# dKc (Kripto Kokpit)

Burak Bey'in coin takip uygulaması; ekranda adı **dKc**. Repo ve adres `kripto-kokpit` olarak kalır. Telefon öncelikli, ana ekrana eklenebilir web uygulaması (GitHub Pages).

- **Ekran:** `index.html`, `app.css`, `app.js` (Kokpit, coin detayı, İşlemlerim, alarmlar); saf hesaplar `hesap.js` (testi: `node test/hesap.test.js`); 15dk göstergeleri `canli.js` (testi: `node test/canli.test.js`). Pozisyon, favori ve sermaye yalnızca cihazda (localStorage) tutulur. Grafik: `lib/lightweight-charts-4.2.0.js` (TradingView Lightweight Charts, Apache 2.0, logo atfı açık).
- **Veri:** Apps Script "Kripto Alarm Motoru" `doGet` (`?k=ANAHTAR&f=ozet` ve `&f=mum&coin=SOL&tf=h4`). Kod: `/mnt/project-files/kripto/alarm-motoru/Kod.gs`.
- **Analiz:** Claude rutinleri günde 4 kez (01:00, 08:00, 13:00, 19:30) `kokpit-analiz-*.json` yazar (bkz. `ANALIZ-FORMATI.md`, kontrol: `analiz-kontrol.js`). Analiz listesi: Coinler sekmesi + hacimde ilk 30 (Kod.gs `coinListesi`).
- **Tarayıcı:** `tarayici/tara.js` GitHub Actions'ta 15 dakikada bir (`.github/workflows/tarayici.yml`) MEXC vadelide hacmi en yüksek 40 coini tarar. Kural: 4S trend (EMA20/50) plan yönünde, 1G ters değil; giriş bölgesi 4S EMA20 ± 0,25 ATR (en az %0,6), stop bölgenin 1 ATR ötesi (en fazla %8), Hedef 1/2 ücret sonrası 1,5R/2,5R; short yalnız hacimde ilk 20; funding filtresi. Sonuç `tarayici-veri` dalında `tarayici.json` (şema `tarayici/sema.json`); Apps Script okur, Claude'un planı olmayan coinlere ekler. Uygulamada "Tarayıcı" etiketi. Sınıf, dominance, 1S onayı ve trafik ışığı Claude planlarıyla aynı kuralla uygulanır. Testi: `node test/tarayici.test.js`.
- **Bildirim:** OneSignal web push (`bildirim.js`, `OneSignalSDKWorker.js`). Apps Script alarm çalınca OneSignal REST API'ye gönderir (`ONESIGNAL_KEY`, `ONESIGNAL_APP_ID` Script Properties'te).
- **Girişe uygun (trafik ışığı):** `hesap.js` `karar()`. Yeşil: analiz plan yönünde hazır, 4S plan yönünde ve 1G ters değil (sınıf A: 1G de aynı yönde, risk %1; sınıf B: 1G yatay, risk %0,5 ve 1S "onay" şart), 1S onaylı (fiyat bölgedeyken sunucu 1 saatlik mumlardan canlı hesaplar: `h1Onay`, `h1Canli`), ücret sonrası Hedef 1 kazanç/riski en az 1,5, 5x içinde, analiz 13 saatten yeni, ters yönde "Yüksek" haber yok, piyasa filtresi (long: "Riskten kaçış" değil, short: "Risk açık" değil), funding aşırı değil ve fiyat giriş bölgesinde. Dominance (`piyasa.dominans`) planın tersine akıyorsa A planı B'ye iner (`dominansEngeli`). Sinyal skoru (`sinyalSkoru`) trafik ışığı yeşil değilken A/A+ vermez; ekran ve bildirim aynı kuralı kullanır. Sarı: plan var, eksik koşul yazılır. Kırmızı: plan yok, geçersiz ya da stop geçildi. Emir değildir.
- **Türev verisi:** coin sayfasında Binance açık verisi (OI ve 24s değişimi, long/short hesap oranı, funding) telefondan doğrudan çekilir, 5 dk saklanır. Bilgi amaçlıdır, karara girmez.
- **Tahmini likidasyon (Likidasyon katmanı):** son 7 günün saatlik Binance açık pozisyon artışı, o saatin fiyatı ve long/short oranıyla 10/25/50/100x kaldıraçta likidasyon fiyatları hesaplanır (`likidasyonHesap`); fiyatın değdiği kümeler silinir, pozisyon azalınca kümeler orantılı küçülür. Grafikte fiyat ekseninin yanında dar ısı şeridi, Türev bölümünde en yoğun küme üstte/altta. Tahmindir, karara girmez; plan stopu kümenin hemen önündeyse yalnız not düşer.
- **Grafik katmanları:** Plan (giriş kutusu, stop/hedef alanı, R), Seviyeler (gri destek/direnç bandı, tepe/dip), RSI · Hacim. Lightweight Charts primitive ile tuvale çizilir. Telefonda varsayılan yalnız Plan.
- **Grafik hızı:** mumlar cihazda saklanır (en fazla 30), grafik anında açılır, arkada yenilenir; ana ekranda önceden yüklenir.
- **Ayar:** `ayar.js`; `api` boşsa uygulama örnek veriyle (`ornek.js`) açılır.

## Yayına alma adımları
1. GitHub `dkcburak/kripto-kokpit` (public) + Pages (main, root). Bu klasörün içeriği repo köküne. `taslak/`, `ANALIZ-FORMATI.md` ve `analiz-kontrol.js` repoya gerekmez.
2. Apps Script'e güncel `Kod.gs` yapıştırılır, `kokpitKurulum` çalıştırılır (PANEL_ANAHTAR oluşur). Script Properties'e `KOKPIT_URL=https://dkcburak.github.io/kripto-kokpit/` eklenir.
3. Dağıt → Yeni dağıtım → Web uygulaması, "Ben olarak çalıştır", erişim "Herkes". `/exec` adresi ve PANEL_ANAHTAR `ayar.js`'e yazılır.
4. OneSignal: App ID `ayar.js`'e ve Script Properties'e (`ONESIGNAL_APP_ID`); REST API Key yalnızca Burak Bey tarafından `ONESIGNAL_KEY` olarak girilir.
5. Telefonda: Safari → Paylaş → Ana Ekrana Ekle → uygulamayı ana ekrandan aç → Alarmlarım → Bildirimleri aç. Sonra `bildirimTest`.
